5. AUTHENTICATION & AUTHORIZATION AUDIT
--------------------------------------------------------------------------------
AUTHENTICATION ENGINE:
- Session Token: JSON Web Token (JWT) signed with HS256 algorithm
- Session Expiry: 14 days (.setExpirationTime("14d"))
- Cookie Name: solvesprint_session (HttpOnly: true, SameSite: "lax", Secure: process.env.NODE_ENV === "production", Path: "/", MaxAge: 14 days)
- Password Storage: bcryptjs with work factor 12 (bcrypt.hash(password, 12))
- Secret Fallback: Hardcoded fallback "dev-only-change-this-solvesprint-secret" used if process.env.AUTH_SECRET is omitted in non-production.

AUTHORIZATION MATRIX:
- Unauthenticated Visitor: View public active challenges & leaderboard; cannot access admin, host dashboard, or submit.
- Student (Non-Member): View public challenges; can create teams or accept invites.
- Student (Team Member): View team submission details; cannot edit submission link.
- Student (Team Lead): View and submit solution links for registered team (submitSolutionAction).
- Organization Host: Scoped access to own hosted challenges and student submissions (app/org/challenges/[id]/page.tsx).
- System Administrator: Full platform administrative access (requireAdmin()).
